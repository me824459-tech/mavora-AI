# MAVORA AI — استودیوی شخصی ساخت ویدیو

**نسخه ۱ (MVP)** | رابط فارسی، مناسب موبایل و دسکتاپ، طراحی مستقل و غیررسمی.

این پروژه از نظر ظاهر و تجربه کاربری با الهام از پلتفرم‌های ساخت ویدیو با هوش مصنوعی طراحی شده، اما **کپی سایت Higgsfield نیست**. موتور اختصاصی ندارد و برای ساخت واقعی ویدیو از **Higgsfield API** استفاده می‌کند.

## امکانات آماده

- ساخت ویدیو از **متن** با مدل Seedance 2.0.
- تبدیل **عکس به ویدیو** با همان مدل؛ آپلود JPG/PNG/WebP تا ۱۰ مگابایت.
- مدت‌های ۵، ۸، ۱۰ یا ۱۵ ثانیه، کیفیت 480p تا 4K، ساخت صدا؛ برای متن نسبت تصویر قابل انتخاب است.
- درخواست ساخت واقعی، دریافت شناسه، بررسی وضعیت، پیش‌نمایش و لینک باز کردن نتیجه.
- آرشیو محلی ۱۰۰ درخواست آخر و پیگیری پس از تازه‌سازی صفحه.
- لغو درخواست‌هایی که هنوز در صف هستند.
- حفاظت از کلید API روی **سرور** و رمز اختیاری مدیر برای استفاده شخصی.
- نمونه ایده‌های آماده. تصاویر گالری فقط آثار هنری نمایشی‌اند، **ویدیوی واقعی ساخته‌شده نیستند**.

## راه‌اندازی روی کامپیوتر

۱. **Node.js 20 یا بالاتر** نصب کن: https://nodejs.org

۲. پوشه را باز کن. فایل `.env.example` را کپی کن و اسم کپی را `.env` بگذار.

۳. در فایل `.env` این مقدار را تکمیل کن:

```env
HF_API_KEY=YOUR_COMPLETE_HIGGSFIELD_API_KEY
HOST=127.0.0.1
PORT=3000
```

کلید را به‌صورت کامل و دقیقاً همان‌طور که از حساب Higgsfield API کپی کردی وارد کن. قسمت `Key ` را به آن اضافه نکن. کلید را **برای من یا هیچ شخص دیگری نفرست**. این برنامه خودش هنگام درخواست سمت سرور از هدر `Authorization: Key ...` استفاده می‌کند.

۴. ترمینال را در همان پوشه باز کن و بزن:

```bash
npm start
```

۵. در مرورگر کامپیوتر آدرس `http://127.0.0.1:3000` را باز کن.

**برای دیدن طرح بدون اتصال:** فایل `public/index.html` را باز کن. در این حالت فقط ظاهر و فرم‌ها قابل پیش‌نمایش هستند؛ تولید ویدیو نیازمند سرور و API است.

## دریافت کلید Higgsfield API

- حساب API: https://open.higgsfield.ai
- ساخت کلید: https://open.higgsfield.ai/api-keys
- در کنسول API روش پرداخت/اعتبار تنظیم کن. **اشتراک معمولی سایت Higgsfield و اعتبار API جدا هستند.** ساخت ویدیو هزینه واقعی دارد و API نیازمند موجودی است.
- برای شروع کیفیت 720p و زمان ۵ ثانیه را انتخاب کن؛ پیش از رفتن به 4K تعرفه همان مدل را چک کن.

## استقرار عمومی / راه‌اندازی برای کاربران دیگر

**این نسخه برای یک مدیر طراحی شده است، نه برای عرضه عمومی و کسب درآمد از مشترکان.** اگر قرار است آن را روی هاست عمومی بالا بیاوری:

- حتماً `HOST=0.0.0.0` و یک `APP_PASSWORD` قوی و تصادفی در متغیرهای محیطی سرور تعیین کن، دامنه **HTTPS** داشته باش و کلید API را فقط در متغیرهای محرمانه سرور نگه دار.
- این رمز فقط برای **مالک واحد** است؛ استفاده عمومی با حساب چند کاربره هنوز ساخته نشده است. پیش از عرضه باید احراز هویت مستقل هر کاربر، مالکیت فایل و درخواست، پرداخت، محدودیت مصرف، کنترل محتوا، سیاست حفظ حریم خصوصی و محافظت در برابر سوءاستفاده اضافه شود.
- درخواست‌ها، متن‌ها و لینک نتایج در `data/jobs.json` روی همان سرور ذخیره می‌شوند؛ از آن نسخه پشتیبان بگیر و فایل را در دسترس عموم قرار نده.
- خروجی‌های Higgsfield ممکن است پس از یک مدت منقضی شوند؛ ویدیوهای مهم را ذخیره کن.
- محدودیت محافظتی داخلی به‌صورت پیش‌فرض **۶ ساخت در ساعت** است (متغیر `MAX_GENERATIONS_PER_HOUR`). این محدودیت جایگزین سقف هزینه در حساب API یا احراز هویت کاربران نیست.

## توضیح فنی

- بدون پکیج خارجی: Node.js HTTP server + HTML/CSS/JavaScript معمولی.
- مدل **متن به ویدیو**: `POST https://api.higgsfield.ai/bytedance/seedance-2.0/text-to-video`
- مدل **عکس به ویدیو**: `POST https://api.higgsfield.ai/bytedance/seedance-2.0/image-to-video`
- عکس: ایجاد signed upload در `/files/generate-upload-url` و آپلود به URL داده‌شده بدون ارسال کلید به میزبان ذخیره‌سازی.
- وضعیت: `GET /requests/{request_id}/status`؛ لغو: `POST /requests/{request_id}/cancel`.
- احراز هویت: `Authorization: Key <complete key>` فقط روی سرور.
- رابط بدون کلید API یا حساب واقعی فقط در حالت پیش‌نمایش کار می‌کند. **اتصال با اعتبار حساب خودت در این محیط آزمایش نشده است.**
