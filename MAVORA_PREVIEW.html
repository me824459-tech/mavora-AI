اتصال موتور ساخت ویدیو

این نسخه آماده است به API رسمی Higgsfield وصل شود. برای شروع:

  1. در پنل Higgsfield API حساب بساز، موجودی اضافه کن و کلید بگیر.
  2. فایل .env.example را به .env تبدیل کن و کلید کامل را در HF_API_KEY قرار بده.
  3. سرور را اجرا یا مجدداً راه‌اندازی کن. کلید را در کد سایت یا مرورگر نگذار.
اشتراک عادی Higgsfield با اعتبار API جداست. بدون کلید و اعتبار، ساخت واقعی ویدیو انجام نمی‌شود.
