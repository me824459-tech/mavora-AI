راهنمای Render برای سایت عمومی MAVORA AI

Environment:
HOST = 0.0.0.0
APP_PASSWORD = (حذف شود یا خالی باشد)
MAX_GENERATIONS_PER_HOUR = 6
HF_API_KEY = کلید خصوصی سرویس (در صورت داشتن)

Start Command: npm start
Build Command: npm install

هشدار: اگر کلید پولی Higgsfield اضافه کنید، کاربران عمومی می‌توانند تا سقف محدودیت از اعتبار شما مصرف کنند. سقف ۶ درخواست در ساعت، سقف هزینه مالی نیست. این نسخه هنوز ورود اختصاصی با حساب گوگل و اعتبار جداگانه کاربران ندارد.
